# STRIDR

Personal running coach for high school and university athletes (ages 13–25): onboarding, 90-day plan, log, reviews, race results.
Single-file static app (index.html). Data is stored in the browser (localStorage).

## Publish on GitHub Pages
1. Create a new public repository on github.com (for example `stridr`).
2. Upload `index.html`, `.nojekyll` and `README.md` (Add file > Upload files).
3. Settings > Pages > Source: Deploy from a branch > `main` / root > Save.
4. After about a minute the site is at `https://YOUR-USERNAME.github.io/stridr/`.

AI coach and account sync are not included in this static version.
No nutrition advice is given. Not medical advice.
